# Contributing

Bug reports, adapter proposals, and diagnostics improvements are welcome.

## Before large changes

Please open an issue describing:
- the adapter or diagnostic you want to add
- the intended observables
- any changes to receipt structure

## Adapter contributions

New adapters should follow the contract described in `ADAPTER_GUIDE.md` and preserve provenance metadata in outputs.

## Diagnostics contributions

If you add a diagnostic, include at least one scientific invariant test when applicable.

## Support

For licensing, collaboration, or deeper instrument work, contact Reachability Labs at mnothem@ReachabilityLab.org.
